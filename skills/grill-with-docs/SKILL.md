# 盘问出文档

同时运用两项技能进行这场访谈：

- 按 **grilling 技能**盘问：把计划或设计画成一棵设计树，按轮次问完前沿上的每个决定，直到达成共识。
- 按 **domain-modeling 技能**留痕：访谈中术语定下来时就地更新 `GLOSSARY.md`；出现难以逆转、且真正做过取舍的决定时，按其格式提议并记录 ADR。

两者并行推进，不要等访谈结束再补文档——术语和决定在成形的那一刻就写下来。
