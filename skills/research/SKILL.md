# 资料调研

派一个**后台子代理**去做这项调研，这样它在读资料的时候主会话还能继续干活。启动它时用全新上下文。

子代理的任务：

1. 针对**一手来源**（官方文档、源代码、规格说明、第一方 API）调研这个问题，而不是去读别人对它们的二手转述。每一条说法都要追回到它的权威出处。
2. 把调研结果写进同一个 Markdown 文件，每条说法都注明来源。
3. 保存到仓库本来就存放这类笔记的地方；沿用既有约定，如果还没有这种约定，就放到一个合理的位置，并说明放在了哪里。
