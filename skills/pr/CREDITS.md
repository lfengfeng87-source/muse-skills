# 致谢

本技能「总结」部分的视觉呈现菜单（伪代码、调用树、组件树、文件树、Mermaid、diff）以及它的摆放指引，取材于 [Dex Horthy](https://github.com/dexhorthy) 的 [`show-me`](https://github.com/humanlayer/humanlayer) 技能，内容基本按原样引入，只是把呈现对象换成了 diff（原技能面向的是一段实时对话场景）。

`pr` 并不把 `show-me` 作为依赖引入——它不属于本技能集，硬依赖会破坏独立安装——所以相关内容是直接收录进来的，而不是靠链接指过去。这份文件就是本应由那份依赖承担的署名说明。
